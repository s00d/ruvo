# sova-tasks

Task worker / scheduler / HTTP enqueue for Sova.

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/tasks](https://s00d.github.io/sova/plugins/tasks)  
**API:** [https://docs.rs/sova-tasks](https://docs.rs/sova-tasks)

## Install

Via the facade (recommended):

```bash
cargo add sova --features tasks
```

Or direct:

```bash
cargo add sova-tasks
```
