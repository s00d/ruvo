# sova-env

Cascade .env loading for Sova apps (dotenvy).

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/env](https://s00d.github.io/sova/plugins/env)  
**API:** [https://docs.rs/sova-env](https://docs.rs/sova-env)

## Install

Via the facade (recommended):

```bash
cargo add sova --features env
```

Or direct:

```bash
cargo add sova-env
```
