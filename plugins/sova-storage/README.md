# sova-storage

Object storage for Sova (local / memory / S3 / GCS / Azure).

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/storage](https://s00d.github.io/sova/plugins/storage)  
**API:** [https://docs.rs/sova-storage](https://docs.rs/sova-storage)

## Install

Via the facade (recommended):

```bash
cargo add sova --features storage
```

Or direct:

```bash
cargo add sova-storage
```
