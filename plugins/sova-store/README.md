# sova-store

KvStore trait + memory / file / sql / redis backends for Sova.

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/store](https://s00d.github.io/sova/plugins/store)  
**API:** [https://docs.rs/sova-store](https://docs.rs/sova-store)

## Install

Via the facade (recommended):

```bash
cargo add sova --features store
```

Or direct:

```bash
cargo add sova-store
```
