# sova-csrf

CSRF protection plugin for Sova (session double-submit).

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/csrf](https://s00d.github.io/sova/plugins/csrf)  
**API:** [https://docs.rs/sova-csrf](https://docs.rs/sova-csrf)

## Install

Via the facade (recommended):

```bash
cargo add sova --features csrf
```

Or direct:

```bash
cargo add sova-csrf
```
