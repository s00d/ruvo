# sova-cors

CORS plugin for Sova.

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/cors](https://s00d.github.io/sova/plugins/cors)  
**API:** [https://docs.rs/sova-cors](https://docs.rs/sova-cors)

## Install

Via the facade (recommended):

```bash
cargo add sova --features cors
```

Or direct:

```bash
cargo add sova-cors
```
