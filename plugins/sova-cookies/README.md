# sova-cookies

Cookie parsing plugin for Sova.

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/cookies](https://s00d.github.io/sova/plugins/cookies)  
**API:** [https://docs.rs/sova-cookies](https://docs.rs/sova-cookies)

## Install

Via the facade (recommended):

```bash
cargo add sova --features cookies
```

Or direct:

```bash
cargo add sova-cookies
```
