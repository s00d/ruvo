# sova-redis

Shared Redis/Valkey pool plugin for Sova.

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/redis](https://s00d.github.io/sova/plugins/redis)  
**API:** [https://docs.rs/sova-redis](https://docs.rs/sova-redis)

## Install

Via the facade (recommended):

```bash
cargo add sova --features redis
```

Or direct:

```bash
cargo add sova-redis
```
