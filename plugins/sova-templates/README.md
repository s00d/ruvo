# sova-templates

Template engine plugin for Sova.

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/templates](https://s00d.github.io/sova/plugins/templates)  
**API:** [https://docs.rs/sova-templates](https://docs.rs/sova-templates)

## Install

Via the facade (recommended):

```bash
cargo add sova --features templates
```

Or direct:

```bash
cargo add sova-templates
```
