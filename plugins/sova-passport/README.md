# sova-passport

Passport-style authentication for Sova (strategies, JWT, OAuth2, sessions).

Part of [Sova](https://crates.io/crates/sova) — Express-like HTTP for Rust.

**Guide:** [https://s00d.github.io/sova/plugins/passport](https://s00d.github.io/sova/plugins/passport)  
**API:** [https://docs.rs/sova-passport](https://docs.rs/sova-passport)

## Install

Via the facade (recommended):

```bash
cargo add sova --features passport
```

Or direct:

```bash
cargo add sova-passport
```
