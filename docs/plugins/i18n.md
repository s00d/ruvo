# `i18n`

**Locales, catalogs, optional path prefix and cookie**

| | |
|--|--|
| Crate | [`sova-i18n`](https://docs.rs/sova-i18n/0.1.2) `0.1.2` |
| Plugin id | `i18n` |
| Category | Content |

## Install

```bash
cargo add sova --features i18n
```

## Features

| Feature | What you get |
|---------|-------------|
| `i18n` | Locales, catalogs, optional path prefix. |
| `i18n-cookie` | Remember locale in a cookie. |

## Overview

**When:** locales, catalogs, optional path prefix / cookie.

**Does:**
- Locale negotiation
- `t!(…)` / catalog lookups
- Path prefix + cookie features

### Example

```rust
app.install(I18n::new().locales(["en", "ru"]).default("en"));
```

## Quick start

Add locales on the **web preset** (templates already available). Cookie locale needs feature `i18n-cookie` (Cookies come from session on the web preset):

```rust
use sova::prelude::*;
use sova::{I18n, Locale, Parser, ServerArgs};

#[tokio::main]
async fn main() -> Result<()> {
    let args = ServerArgs::parse();
    args.init_tracing();

    let mut app = App::web()
        .site("App")
        .public_url("https://example.com")
        .into_app();

    app.install(
        I18n::new(
            "locales",
            vec![
                Locale::new("en").with_name("English"),
                Locale::new("ru").with_name("Русский"),
            ],
        )
        .fallback("en")
        .cookie("locale")
        .set_locale_cookie(true),
    );

    app.run().await
}
```

In MiniJinja register the helper with `sova_templates::register_per_request(app, "t", sova::template_fn)` (or build `Templates::minijinja(…).per_request(…)` yourself). Demos: `i18n`, `templates_i18n`.
