**When:** locales, catalogs, optional path prefix / cookie.

**Does:**
- Locale negotiation
- `t!(…)` / catalog lookups
- Path prefix + cookie features

### Example

```rust
app.install(I18n::new().locales(["en", "ru"]).default("en"));
```

### Config

```toml
[i18n]
default = "en"
cookie = "locale"    # needs feature i18n-cookie + CookieLayer
watch = true         # hot-reload catalogs when feature allows
```
